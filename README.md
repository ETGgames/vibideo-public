# Vibideo

Public bug reports and feature requests for Vibideo.

- [Search existing reports and requests](https://github.com/ETGgames/vibideo-public/issues)
- [Report a bug](https://github.com/ETGgames/vibideo-public/issues/new?template=bug_report.md)
- [Request a feature](https://github.com/ETGgames/vibideo-public/issues/new?template=feature_request.md)

Search existing issues before opening a new one. If someone has already reported the same problem or idea, add a reaction or useful details there.

You need a GitHub account to submit an issue or comment.

## Public information

Issues, comments and attachments are public. Remove personal details, passwords, tokens, private project links and private media before posting. Screenshots are optional.

This repository tracks feedback. It does not contain the app's source code.
